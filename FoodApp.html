Android App Food Delivery Firebase

Food Delivery App

An Android-based food ordering system where admin uploads dishes and users can place Normal or Special orders — powered by Firebase for real-time data management.

View on GitHub Back to Portfolio
Android (Java) Firebase Realtime DB Firebase Auth Firebase Storage Email Notification Admin Panel

Project Overview

  • Admin uploads dishes with name, price, image & description
  • Users browse dishes and place Normal or Special orders
  • Firebase handles all real-time data, auth & storage

Two User Roles

  • User — Register, browse dishes, place orders, view history
  • Admin — Approve users, manage dishes, monitor all orders
  • Role-based access control with separate dashboards

Order Types

  • Normal Order — Select any dish and place order instantly
  • Special Order — Minimum 5 dishes required for bulk ordering

Key Features

  • Admin approval system for new registrations
  • Email confirmation sent on account approval
  • Favorites, profile management & order history

Admin Control

Signup Approval Flow

Every new registration goes through admin verification before the user can access the app — ensuring platform security.

  • Registration request auto-sent to admin panel
  • Admin views all pending users with full details
  • Admin approves or rejects each account
  • Confirmation email sent to user upon approval
  • User can then login and access the app
